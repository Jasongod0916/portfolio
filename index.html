3D Printing Tool

STL Splitter：3D 模型裁切與定位孔工具

讓超出列印尺寸的 3D 模型也能分件製作。在瀏覽器中載入 STL、調整切割位置並配置定位孔，將零件與定位銷一次匯出為 ZIP，方便後續列印與組裝。

以模型切成兩件、配置 2 個定位孔並匯出為例，預估操作時間可由手動建模的約 15 分鐘縮短至 5 分鐘，節省約 67%。

3D Printing Tool

3D 條碼載具卡產生器

3D Printing Tool

3D 條碼載具卡產生器

將條碼文字轉成可 3D 列印的實體載具卡。支援 Code 39 與 Code 128，可調整卡片尺寸、底板厚度及條碼凸起高度，匯出 STL、分件 3MF 與 SVG，方便單色或多色列印。

已發布至 MakerWorld 3D 列印社群，讓使用者從線上產生條碼卡，到下載模型並實際列印。
